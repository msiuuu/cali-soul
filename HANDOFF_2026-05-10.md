### Build prereqs to install (in order):

```powershell
# Rust
irm https://win.rustup.rs/x86_64 -OutFile rustup-init.exe
.\rustup-init.exe -y

# VS Build Tools — install via the GUI, choose "Desktop development with C++"
# https://visualstudio.microsoft.com/downloads/

# Node.js LTS
# https://nodejs.org/

# pnpm
npm install -g pnpm

# uv
irm https://astral.sh/uv/install.ps1 | iex
```

### Build sequence:

```powershell
git clone https://github.com/hanamorix/companion-emergence
cd companion-emergence
uv sync --all-extras
cd app
pnpm install
# IMPORTANT: enable devtools BEFORE building. edit src-tauri/tauri.conf.json
# or pass --dev flag, depending on Tauri 2 conventions.
pnpm tauri build
```

After build, the bundled app lands in
`app/src-tauri/target/release/bundle/msi/` (or nsis).

Then reapply our daemon.py patch:
```powershell
cd C:\Users\yuscr\cali-soul
python patch_daemon.py
# (note: this patches the OLD install location. for source build,
# the daemon.py will be at companion-emergence/brain/bridge/daemon.py
# instead. update patch_daemon.py path accordingly.)
```

### Then debug:

1. Launch source-built NellFace
2. Press F12 (devtools should be enabled now)
3. Console tab → look for actual JS error when state-poll fires
4. Network tab → see what HTTP request actually goes out, what response
   comes back

The actual error message will tell us if it's CORS, mixed-content,
DNS, or something else. We've been blind-debugging until now.

### Likely candidates for the bug:

- **Tauri WebView2 loopback isolation** — Windows AppContainer apps
  are sometimes blocked from loopback by default. Tauri 2 with
  WebView2 might need `CheckNetIsolation LoopbackExempt` registration.
  Tauri usually handles this but might fail on this build.
- **Mixed-content blocking** — frontend is on https://tauri.localhost,
  trying to fetch http://127.0.0.1. Some webviews block this even
  with CSP `connect-src` allowing it.
- **Cookie/auth handling** — Bearer token in header should be fine
  but webview might strip it.
- **HTTP/HTTPS mismatch in some specific path**
